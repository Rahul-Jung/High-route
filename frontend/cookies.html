Cookies

Short, because there is very little to say — and it is written from what the code does rather than from a template.

There is no cookie banner, and that is deliberate

A consent banner is required when a site sets cookies that are not strictly necessary — analytics, advertising, tracking. This site sets none of those, so a banner would have nothing to ask you about.

You have probably met a banner that asks for consent and then loads the trackers anyway, or one where "reject" does nothing. The brief this site was built to forbids exactly that: a consent interface that does not control the behaviour it claims to control. The honest version of that requirement, on a site with no trackers, is no banner and this page.

What is actually stored in your browser

Not cookies, as it happens — browser storage, which does the same job and is covered by the same rules. The complete list:

Strictly necessary

  • Your session token, once you sign in. Without it you would be signed out on every page load. Stored as a token that the server matches against a hash; clearing it signs you out.

Functional, and only if you use the feature

  • Your Adventure Finder answers, in session storage, so that following a result and coming back does not lose them. Cleared when you close the tab, and also held in the page URL, which is why a finder result is shareable.

Not present

  • No analytics cookies. There is no analytics on this site.
  • No advertising or cross-site tracking cookies.
  • No social media pixels or embedded like buttons.
  • No session recording or heatmaps.

Third-party requests

Two things on these pages are loaded from somewhere else, and both can see your IP address as a consequence of being requested, in the way that loading any remote file does:

  • Google Fonts (fonts.googleapis.com) — the three typefaces this site uses.
  • Unsplash (images.unsplash.com) — the photographs.

Neither sets a cookie through this site. Self-hosting both would remove the third-party request entirely and is the right thing to do before launch; it is on the list.

Clearing it

Signing out removes the session token. Clearing site data for this domain in your browser removes everything listed above. Nothing here survives that, and nothing here is stored anywhere else as a copy.

If this ever changes

If analytics or any non-essential cookie is added to this site later, this page has to change and a real consent mechanism — one that actually gates the loading of the script — has to come with it. A banner added without that would be worse than none.
